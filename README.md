# 🌤️ Weather App with Azure

A Python Flask weather application integrated with Azure Cosmos DB and deployed on Azure App Service.

## 🔗 Live App
👉 http://weather-azure-app-mgk.azurewebsites.net

## 🛠️ Tech Stack
- Python + Flask
- OpenWeatherMap API
- Azure Cosmos DB
- Azure App Service

## ⚙️ Features
- Search live weather for any city worldwide
- Saves search history to Azure Cosmos DB in real time
- Deployed live on Azure App Service (Central India)
